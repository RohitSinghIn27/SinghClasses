Q1
Guido van Rossum released Python's first official version in:
1 Mark
Correct Answer: (b) 1991. Guido van Rossum started implementation in December 1989, and published version 0.9.0 in February 1991.
Q2
Which of the following starts a valid single-line comment in Python?
1 Mark
Correct Answer: (c) # Comment. Python uses the hash symbol (#) for single-line comments. // is floor division in Python.
Q3
Which file extension is used for Python programs that do NOT need a console window (e.g., GUI apps)?
1 Mark
Correct Answer: (c) .pyw. .pyw files run using pythonw.exe, which suppresses the standard DOS terminal/command prompt window.
Q4
Python source code is translated and executed line-by-line using a/an:
1 Mark
Correct Answer: (d) Interpreter. An interpreter takes one instruction at a time, checks syntax, converts to bytecode, and executes immediately.

  • (iii) The returned type of input() is always _____________.

Answers:
(i) Modula-3

▶ C Section C: Error Diagnosis & Tracing
4 Marks (2 Qs)
Q7
A student writes the following script:
marks = 95 print("Your total marks are: " + marks)
(a) Identify the exact error.
(b) Explain why it fails.
(c) Rewrite the statement correctly in two distinct ways.
2 Marks
(a) Error: TypeError: can only concatenate str (not "int") to str.
(b) Reason: In Python, the + operator cannot concatenate a string literal with an integer without conversion.
(c) Valid Corrections:
  • Method 1: print("Your total marks are: " + str(marks))
  • Method 2: print("Your total marks are:", marks)
Q8
Trace and predict the exact output of this consecutive sequence:
print(10, 20, sep='-', end='*') print(30, 40, sep='/')
2 Marks
Output:
10-20*30/40
Explanation: The first line replaces newline with *, so the second line starts printing on the exact same row.
▶ D Section D: Short Answer & Language Processors
4 Marks (2 Qs)
Q9
State two differences between an Interpreter and a Compiler. Why does an interpreter benefit a beginner learning to code?
2 Marks
Key Differences:
  • Translation Style: Interpreters execute line-by-line. Compilers translate the whole source code into object code in one pass.
  • Error Reporting: Interpreters halt at the first encountering error; compilers list all errors collectively.
Beginner Advantage: Line-by-line feedback pinpoints the exact line where a mistake occurred, easing debugging.
Q10
Distinguish between Source Code and Object Code. Which one is executed by the CPU directly?
2 Marks
Source Code: High-level program text written in human-readable syntax by programmers (e.g. .py files).
Object Code: Low-level binary/machine code produced after translation by a language processor.
Execution: Only Object Code (Machine Code) can be executed directly by the CPU.

💡 Rapid Study Notes

Chapter 2 Key Takeaway:

Python is an interpreted, high-level, dynamically typed language. Variable types do not need to be declared before assignment.

Input & Output Nuances:

# String formatting print("A", "B", sep="-") # -> A-B print("A", end="") # No newline appended name = input("Name: ") # Returns str always!

Operators:

+ on two numbers = addition.

+ on two strings = concatenation.

* with string and integer = string replication.
