🎯 Most Important Questions (Click to Reveal)
CBSE Favorite
Q1. Why does len('\n') evaluate to 1? ▼
An escape sequence consists of a backslash followed by a character, but Python parses it as a single non-printable character token.
Q2. Distinguish between == and is operator. ▼
== checks for value equality, whereas is tests memory identity (whether both variables point to the same id()).
Q3. Predict output: print(-7 // 2, 2 ** 3 ** 2) ▼
Output: -4 512. Floor division rounds down towards negative infinity (-3.5 floors to -4), and exponentiation evaluates right-to-left (3**2=9, then 2**9=512).
💡 CBSE Exam Traps & Tips
Must Read
  • Division Trap: True division / in Python 3 always yields a float (e.g. 6 / 3 produces 2.0, not 2).
  • Reserved Capitalization: Exactly three keywords start with an uppercase letter: True, False, and None.
  • Identifier Rules: Identifiers can never begin with digits or contain hyphens (e.g. 2nd_var and my-val cause a SyntaxError).

1. Classification of Tokens (Lexical Units)

A token is the smallest individual unit in a program. Python has 5 core token types:

Token Type Description Examples
Keywords Reserved words with predefined compiler meaning. if, else, for, while, def, return
Identifiers Names of variables, functions, and objects. count, total_score, _val
Literals Constant data values directly written in code. 100, 3.14, 'Hello', True, None
Operators Symbols triggering computation on operands. +, -, *, /, //, %, **, ==, is
Punctuators Organizing symbols and grouping delimiters. ( ), [ ], { }, :, ,, .

2. Mutable vs Immutable Types

Category Characteristics Python Types
Immutable Cannot be modified in-place; alterations create new memory objects. int, float, complex, bool, str, tuple
Mutable Values can be altered without altering original memory address (id). list, dict, set

3. Operator Precedence Hierarchy (High to Low)

Parentheses () > Exponentiation ** (Right-to-Left) > Unary +, - > Multiplication/Division *, /, //, % > Addition/Subtraction +, - > Relational <, >, ==, != > Identity/Membership is, in > Logical not > and > or.
