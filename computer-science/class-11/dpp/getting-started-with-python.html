Q7. A student executes this code:
2 Marks
script.py
marks = 95
print("Your total marks are: " + marks)
(a) Identify the exact error • (b) Why does it fail? • (c) Provide two working corrections.
📝 Self-Draft Workspace
🔍 Model Error Breakdown
Error: TypeError: can only concatenate str (not "int") to str
Why: Python is strongly typed and prohibits automatic implicit coercion between textual strings and numeric integers.
Corrections: (1) print("Your total marks are: " + str(marks)) [Type Casting / Explicit Conversion] • (2) print("Your total marks are:", marks)
⚠️ CBSE Trap: Using a comma automatically appends a space, while concatenation with + requires manual spacing!

Q9. State two differences between an Interpreter and a Compiler. Why is an interpreter uniquely beneficial for a beginner debugging errors?
2 Marks
📝 Self-Draft Workspace
🔍 Architecture Comparison
Execution Mode: Interpreters translate and execute statement-by-statement; compilers scan and translate the entire source program in a single pass into machine binaries.
Bytecode: Modern Python creates intermediate Bytecode (.pyc) interpreted by the Python Virtual Machine (PVM).
Debugging: Halting execution immediately at the exact erroneous line provides beginner students with targeted, localized feedback.
Q10. Distinguish between Source Code and Object Code. Which of these two is directly executed by the CPU?
2 Marks
📝 Self-Draft Workspace
🔍 Execution Hierarchy
Source Code: High-level, human-readable program instructions written by programmers (e.g., Python code).
Object Code: Low-level machine language binary instructions (0s and 1s) produced after compilation or translation.
Direct Execution: Only Object Code can be directly processed and executed by the Central Processing Unit (CPU).
