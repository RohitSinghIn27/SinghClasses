Q7 • Tricky • 2 Marks Type System & Exceptions
A student executes this code:
marks = 95 print("Your total marks are: " + marks)
(a) Identify the exact error • (b) Why does it fail? • (c) Provide two working corrections.
🔍 Model Error Breakdown
Error: TypeError: can only concatenate str (not "int") to str
Why: Python is strongly typed and prohibits automatic implicit coercion between string text and numeric integers.
Corrections: (1) print("Your total marks are: " + str(marks)) • (2) print("Your total marks are:", marks)
⚠️ CBSE Trap: Using a comma automatically appends a space, while + requires you to format spaces manually!

Stage 5
Q9 • Medium • 2 Marks Compiler vs Interpreter
State two differences between an Interpreter and a Compiler. Why is an interpreter uniquely beneficial for a beginner debugging errors?
🔍 Architecture Comparison
Mode: Interpreters translate instruction-by-instruction; compilers translate the entire program in one pass.
Files: Compilers create standalone object binaries (.exe); interpreters execute directly in memory.
Debugging: Halting execution at the exact faulty line gives beginners immediate, localized feedback.
Q10 • Easy • 2 Marks Machine Execution
Distinguish between Source Code and Object Code. Which of these two is directly executed by the CPU?
🔍 Execution Hierarchy
Source: High-level, human-written instructions (e.g. Python script).
Object: Machine-level binary instructions produced after language translation.
CPU: Only Object Code can be executed directly by the CPU hardware.
