01
State True or False: In Python, the data type of 74 is the same as the data type of 74.0.
Correct Answer: (B) False
74 is an integer (int) while 74.0 is a floating-point number (float).

02
What is the output of the following code?
s = "the Truth"
print(s.capitalize())
> The truth
Correct Answer: (A) The truth
capitalize() converts the first character to uppercase and all other characters to lowercase.
1 mark
03
Which of the following expressions evaluates to True?
Correct Answer: (C) 3 > 1 and 3 > 2
Both conditions evaluate to True; in Python True and True produces True.
1 mark
04
What is the output of the following code?
s = 'War and Peace by Leo Tolstoy'
print(s.partition("by"))
> ('War and Peace ', 'by', ' Leo Tolstoy')
Correct Answer: (A)
str.partition(sep) splits at the first occurrence and always returns a 3-tuple: (head, sep, tail).
1 mark
05
What is the output of the following slicing statement?
print("PythonProgram"[-1:2:-2])
> mroPo
Correct Answer: (B) mroPo
Traversed reverse indices: -1 ('m'), -3 ('r'), -5 ('o'), -7 ('P'), -9 ('o').
1 mark
06
What is the output of the following code?
t = tuple('tuple')
t2 = t[2],
t += t2
print(t)
> ('t', 'u', 'p', 'l', 'e', 'p')
Correct Answer: (C) ('t', 'u', 'p', 'l', 'e', 'p')
Trailing comma makes t2 a 1-tuple ('p',) which concatenates to the unpacked tuple.
1 mark
07
Which statement about Python dictionaries is true?
Correct Answer: (B)
Dictionary keys must be unique and immutable. Duplicate keys overwrite previous values.
1 mark
08
If L is a list with 6 elements, which statement will raise an exception?
Correct Answer: (B) L.pop(6)
A 6-element list has valid indices 0 to 5. Index 6 triggers IndexError: pop index out of range.
