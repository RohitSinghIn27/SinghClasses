07
Write a function CountVowels(filename) in Python to count and return the total number of vowels present in the text file "Story.txt".
Solution:
def CountVowels(filename):
    count = 0
    with open(filename, 'r') as f:
        content = f.read()
        for ch in content:
            if ch.lower() in 'aeiou':
                count += 1
    return count
3 marks
08
Consider table STUDENT(RollNo, Name, Marks, Stream). Write SQL queries to:
(i) Display all records of Science stream students having Marks > 80.
(ii) Count total students enrolled per Stream.
(iii) Increase Marks by 5 for students scoring less than 33.
SQL Queries:
(i) SELECT * FROM STUDENT WHERE Stream = 'Science' AND Marks > 80;
(ii) SELECT Stream, COUNT(*) FROM STUDENT GROUP BY Stream;
(iii) UPDATE STUDENT SET Marks = Marks + 5 WHERE Marks < 33;
5 marks
