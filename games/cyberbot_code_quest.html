📖 CyberBot API & Syntax Reference

All available methods callable on the autonomous robot instance.

Movement & Navigation

  • bot.forward() or bot.step(n=1): Move robot forward 1 (or n) tiles in current facing direction.
  • bot.backward(): Step 1 tile backward without changing orientation.
  • bot.turnLeft(): Rotate 90 degrees counter-clockwise.
  • bot.turnRight(): Rotate 90 degrees clockwise.
  • bot.jump(): Leap over a 1-tile gap, pit, or active laser barrier directly in front.

Sector Interaction

  • bot.collect(): Harvest the glowing energy core on the current tile.
  • bot.activate(): Toggle terminal switch on current tile to drop linked laser gates.
  • bot.log(message): Transmit diagnostic string directly into the cyber terminal.

Sensors (Conditionals & Loops)

  • bot.isPathClear(): Returns true if the tile directly ahead is safe and walkable.
  • bot.isWallAhead(): Returns true if facing a solid barrier or border wall.
  • bot.isLaserAhead(): Returns true if an energized laser beam lies ahead.
  • bot.isGemAhead(): Returns true if an uncollected core is in the adjacent tile.
  • bot.isAtGoal(): Returns true if the robot is stationed inside the extraction portal.
  • bot.hasGemsRemaining(): Returns true if any unharvested cores remain on grid.
